VARsha Portfolio Website

HOW TO RUN
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in a browser, or right-click index.html and choose "Open with Live Server".

FILES
- index.html: Portfolio content and sections
- style.css: Layout, colours, typography and responsive design
- script.js: Mobile navigation and current year

You can edit your personal details and text directly in index.html.
